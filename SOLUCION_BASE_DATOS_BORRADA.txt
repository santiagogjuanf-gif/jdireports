¿POR QUÉ PASÓ ESTO?
═══════════════════════════════════════════════════════════════════

MySQL en XAMPP puede perder datos si:
- Se apaga Windows sin detener MySQL primero
- Hay un error de disco o corrupción
- Las tablas se crean en memoria temporal (modo MEMORY engine)

PARA EVITARLO EN EL FUTURO:
- Siempre detén MySQL en XAMPP antes de apagar Windows
- Haz backups regulares de la base de datos
- Verifica que el motor de las tablas sea InnoDB (no MEMORY)
