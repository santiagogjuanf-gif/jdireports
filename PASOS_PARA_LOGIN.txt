========================================
🚀 PASOS PARA SOLUCIONAR EL LOGIN
========================================

El problema actual es que las dependencias de Node.js no están instaladas.
Sigue estos pasos en orden:

----------------------------------------
PASO 1: INSTALAR DEPENDENCIAS
----------------------------------------

Abre PowerShell o CMD en la carpeta del proyecto y ejecuta:

    cd C:\xampp\htdocs\jdireports
    npm install

Esto instalará todas las dependencias necesarias, incluyendo bcryptjs
que es el módulo que falta para verificar contraseñas.

⏱️  Este proceso tomará 1-3 minutos.

----------------------------------------
PASO 2: CREAR USUARIO ADMINISTRADOR
----------------------------------------

Después de que npm install termine, ejecuta este script:

    node backend/scripts/create-admin.js

Este script:
✅ Generará un hash de contraseña correcto
✅ Eliminará cualquier usuario admin anterior
✅ Creará un nuevo usuario admin en la base de datos
✅ Te mostrará las credenciales de login

----------------------------------------
PASO 3: REINICIAR EL SERVIDOR
----------------------------------------

Si el servidor está corriendo, detenerlo con Ctrl+C y reiniciarlo:

    node backend/server.js

Deberías ver:
    ✅ Conexión a MySQL establecida correctamente
    🚀 Servidor corriendo en http://localhost:3000

----------------------------------------
PASO 4: PROBAR EL LOGIN
----------------------------------------

1. Abre el navegador en: http://localhost:3000/login

2. Usa estas credenciales:
   Usuario:    admin
   Contraseña: Admin123!

3. Deberías entrar al dashboard correctamente

4. Puedes cambiar el idioma con los botones en la esquina superior derecha

========================================
❓ SI HAY PROBLEMAS
========================================

PROBLEMA: npm install da error de permisos
SOLUCIÓN: Ejecuta PowerShell como Administrador

PROBLEMA: npm install da error "npm no se reconoce"
SOLUCIÓN: Node.js no está en el PATH. Reinstala Node.js desde nodejs.org

PROBLEMA: El script create-admin.js da error "Cannot find module"
SOLUCIÓN: Verifica que npm install haya terminado correctamente

PROBLEMA: Error de conexión a MySQL
SOLUCIÓN: Verifica que XAMPP esté corriendo y MySQL esté iniciado

PROBLEMA: Login sigue dando 401
SOLUCIÓN:
  1. Verifica que el usuario admin exista en la tabla users
  2. Ejecuta de nuevo: node backend/scripts/create-admin.js
  3. Reinicia el servidor

========================================
📞 INFORMACIÓN ADICIONAL
========================================

El problema que teníamos era:
- El frontend enviaba las credenciales correctamente ✅
- El backend recibía la petición correctamente ✅
- PERO bcryptjs no estaba instalado ❌
- Por eso no podía verificar la contraseña ❌

Después de ejecutar npm install, bcryptjs estará disponible
y el login funcionará correctamente.
